# Présentation des fonctionnalités de FERM+

## 1. Présentation générale

FERM+ est une application de gestion agricole conçue pour aider les exploitants, responsables de ferme et propriétaires à piloter leurs activités dans un seul espace numérique.

La plateforme centralise les opérations techniques, les mouvements de stock, les données financières, les alertes, les tâches et les rapports, avec une logique de traçabilité adaptée aux réalités du terrain.

## 2. Objectif de l'application

FERM+ permet de :

- structurer la gestion quotidienne d'une ferme ;
- suivre les opérations par module métier ;
- relier les mouvements techniques aux impacts financiers ;
- améliorer la traçabilité, la supervision et la prise de décision ;
- offrir un espace unique par ferme, sécurisé et organisé.

## 3. Types d'utilisateurs

L'application fonctionne avec deux profils :

### Administrateur

L'administrateur pilote la ferme et dispose des droits de gestion.

Il peut notamment :

- créer et gérer la ferme ;
- enregistrer les opérations métier ;
- créer les comptes propriétaires ;
- gérer les stocks, les tâches, les alertes et les données financières ;
- consulter les rapports ;
- administrer les paramètres.

### Propriétaire

Le propriétaire dispose d'un accès en lecture seule.

Il peut consulter :

- les stocks ;
- les mouvements ;
- les performances de production ;
- les alertes ;
- les finances ;
- les rapports ;
- l'état global de la ferme.

## 4. Principe d'organisation

FERM+ repose sur une règle forte :

`1 administrateur = 1 ferme = 1 espace de travail privé`

Cette organisation permet :

- une meilleure séparation des données ;
- un meilleur contrôle des accès ;
- une gestion plus claire des responsabilités ;
- une réduction des risques de mélange entre plusieurs fermes.

## 5. Modules fonctionnels principaux

## 5.1 Tableau de bord

Le tableau de bord donne une vue d'ensemble rapide de l'activité de la ferme.

Il met en avant :

- les indicateurs clés ;
- les alertes importantes ;
- les niveaux de stock ;
- l'état des tâches ;
- les grandes tendances par module ;
- une lecture économique simplifiée.

## 5.2 Gestion des utilisateurs et des accès

Le système d'accès permet :

- la création du compte administrateur ;
- la création de comptes propriétaires rattachés à la ferme ;
- la gestion de l'état des comptes ;
- le changement et la réinitialisation des mots de passe ;
- la séparation stricte entre gestion et consultation.

## 5.3 Gestion de l'élevage

Le module élevage permet de suivre les lots d'animaux.

Fonctionnalités principales :

- création et mise à jour de lots ;
- suivi des effectifs ;
- suivi des mortalités ;
- alimentation des animaux ;
- plans d'alimentation ;
- pesées ;
- lien avec les bâtiments ;
- prise en compte des impacts financiers liés aux opérations.

## 5.4 Module pondeuses

Le module pondeuses est dédié à la gestion des lots de poules pondeuses.

Il permet de :

- créer des lots ;
- enregistrer la production d'œufs ;
- suivre les ventes ;
- relier les ventes aux revenus ;
- relier la production aux stocks ;
- enregistrer l'alimentation ;
- suivre la performance par lot.

## 5.5 Module pisciculture

Le module pisciculture permet de gérer les bassins et les activités aquacoles.

Il prend en charge :

- la création de bassins ;
- les mises en charge ;
- le suivi des effectifs ;
- les suivis techniques ;
- les récoltes ;
- les ventes ;
- les liens avec les stocks et les finances.

## 5.6 Module cultures

Le module cultures permet de gérer les activités végétales.

Il couvre :

- les parcelles ;
- les campagnes culturales ;
- les opérations culturales ;
- les récoltes ;
- les ventes ;
- les coûts d'exploitation ;
- les liens entre production et comptabilité.

## 5.7 Gestion des stocks et intrants

Le module stocks et intrants permet une gestion plus professionnelle des articles et consommables.

Il gère :

- les articles de stock ;
- les catégories ;
- les unités ;
- les fournisseurs ;
- les emplacements ;
- les quantités disponibles ;
- les mouvements d'entrée, de sortie et d'ajustement ;
- les prix unitaires ;
- les valeurs d'achat ;
- la traçabilité des lots, références et péremptions ;
- les usages liés aux autres modules métier.

Ce module est conçu pour connecter la logistique à la comptabilité et à la traçabilité financière.

## 5.8 Gestion sanitaire

Le module sanitaire permet de suivre les traitements et opérations liées à la santé animale.

Il permet notamment :

- l'enregistrement des traitements ;
- le suivi des dates ;
- le dosage ;
- les coûts ;
- la mise à jour du statut d'administration ;
- la liaison avec les stocks concernés lorsque cela s'applique.

## 5.9 Gestion des bâtiments et infrastructures

Ce module permet de structurer les espaces physiques de la ferme.

Il permet :

- de créer des bâtiments ;
- de décrire leur usage ;
- de suivre leur état ;
- de rattacher des activités ou des lots à ces infrastructures.

## 5.10 Tâches et agenda

FERM+ intègre un système d'organisation du travail.

Fonctionnalités :

- création de tâches ;
- dates de début et de fin ;
- priorités ;
- statuts ;
- rattachement au module source ;
- visualisation agenda ;
- aide au suivi opérationnel.

## 5.11 Centre d'alertes

Le centre d'alertes permet de remonter rapidement les anomalies et urgences.

Il prend en compte :

- les alertes opérationnelles ;
- les alertes de stock ;
- les alertes critiques ;
- les rappels d'action ;
- la supervision des éléments nécessitant une attention rapide.

## 5.12 Finances et livre de gestion

Le module finances centralise les revenus et les dépenses.

Il permet :

- de créer des transactions manuelles ;
- de recevoir automatiquement des écritures depuis les modules métier ;
- de suivre les charges et les revenus ;
- de lire plus clairement la rentabilité ;
- de tracer les impacts financiers liés aux opérations de terrain.

L'intérêt majeur de FERM+ est justement de ne pas séparer la technique de la comptabilité.

## 5.13 Rapports

Le module rapports permet d'extraire et de synthétiser les données de la ferme.

Il propose :

- des vues synthétiques ;
- des sections par domaine ;
- des exports ;
- une lecture plus claire des activités et résultats.

## 5.14 Audit et traçabilité

L'application conserve une traçabilité des actions sensibles.

Cela permet :

- de savoir qui a fait quoi ;
- de sécuriser les opérations importantes ;
- de renforcer la confiance dans les données ;
- d'améliorer le contrôle interne.

## 6. Interconnexion entre les modules

L'un des points forts de FERM+ est l'interconnexion des modules.

Exemples :

- une vente peut produire un revenu en finance ;
- une consommation d'intrant peut affecter le stock ;
- une opération de production peut enrichir les rapports ;
- une baisse de stock peut déclencher une alerte ;
- une activité métier peut être reliée à une tâche ou à un calendrier.

Cette logique permet d'éviter les doubles saisies et de renforcer la cohérence globale de l'information.

## 7. Synchronisation et usage multi-supports

FERM+ peut être utilisé sur ordinateur et sur tablette.

L'objectif est de permettre :

- la consultation sur plusieurs supports ;
- la mise à jour plus fluide des données ;
- une expérience d'utilisation adaptée au terrain comme au bureau ;
- une continuité de travail pour l'administrateur et le propriétaire.

## 8. Sécurité et contrôle

L'application intègre plusieurs principes de sécurité :

- séparation des rôles ;
- contrôle des accès ;
- isolation des données par ferme ;
- limitation des actions du propriétaire ;
- traçabilité des opérations ;
- validation des données côté backend ;
- protection renforcée sur l'authentification et les opérations sensibles.

## 9. Valeur ajoutée de FERM+

FERM+ apporte plusieurs bénéfices :

- centralisation de la gestion agricole ;
- meilleure organisation du travail ;
- meilleure lisibilité financière ;
- meilleure traçabilité des intrants et opérations ;
- meilleure supervision de la production ;
- réduction des oublis et des écarts de gestion ;
- support à la prise de décision.

## 10. Exemples d'usage

### Exemple 1 : suivi d'un lot de pondeuses

L'administrateur crée un lot, enregistre l'alimentation, la production d'œufs, puis les ventes.  
Les données techniques, de stock et de finance restent cohérentes dans le même système.

### Exemple 2 : gestion d'un intrant

L'administrateur crée un article de stock avec son prix unitaire, sa référence, son fournisseur et son emplacement.  
Lorsqu'il est utilisé dans une activité métier, l'information reste traçable dans les stocks et dans la logique financière.

### Exemple 3 : suivi d'une campagne culturale

L'administrateur crée une parcelle, lance une campagne, saisit les opérations, puis enregistre récoltes et ventes.  
Les coûts et résultats sont alors visibles dans les rapports et les finances.

## 11. Conclusion

FERM+ est une plateforme de gestion agricole conçue pour offrir une vision plus structurée, plus traçable et plus professionnelle de l'exploitation.

Elle ne se limite pas à enregistrer des données : elle relie les opérations du terrain, les stocks, les finances, les alertes et les rapports dans un même environnement de gestion.

En résumé, FERM+ aide la ferme à :

- mieux produire ;
- mieux organiser ;
- mieux suivre ;
- mieux décider ;
- mieux contrôler.
