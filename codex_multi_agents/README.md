# Pack Multi-Agents Codex

Ce dossier contient un système de 10 agents IA pour accompagner le développement d'applications avec Codex.

## Installation
Copie :
- `AGENTS.md`
- `PROJECT_STATUS.md`
- le dossier `agents/`

à la racine de ton projet.

## Démarrage recommandé
Demande à Codex :

> ORION, analyse complètement ce repository. Fais un audit de l’état actuel du projet sans modifier le code. Identifie ce qui fonctionne, ce qui est incomplet, les bugs, les risques de sécurité et les priorités.

Ensuite :

> ORION, continue le développement de la priorité n°1 en utilisant les agents spécialisés nécessaires. Vérifie le build et les tests avant de terminer.

## Conseil
Utilise un pack identique dans chaque projet, mais garde un `PROJECT_STATUS.md` différent par application.
